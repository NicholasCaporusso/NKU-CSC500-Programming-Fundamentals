Northern Kentucky University

CSC500 — Programming Fundamentals

Lecture slides for all sixteen weeks, generated from the course lecture notes. Each deck condenses its week onto presentable slides while keeping every code example verbatim; the surrounding detail lives in expandable sections, concept modals, and speaker notes.

Week 1

Computational Thinking and Java Basics

What programs do; source code, compilation, the JVM; variables; primitive types; expressions; console I/O; assignment.

Lab focus: Set up a Java environment, compile and run programs, write small numerical programs
Week 2

Decisions and Boolean Logic

if, else, nested conditionals, relational and logical operators, boolean expressions, input validation.

Lab focus: Build programs with branching logic; debug conditional errors
Week 3

Loops and Iteration

while, for, do-while; counters, accumulators, sentinel loops; nested loops.

Lab focus: Simulation and data-processing exercises; trace program execution
Week 4

Methods and Program Decomposition

Method definitions, parameters, return values, scope, local variables, the call stack, decomposition.

Lab focus: Refactor monolithic programs into reusable methods
Week 5

Arrays and Strings

1-D arrays, traversal, indexing, strings, StringBuilder, basic searching and counting.

Lab focus: Analyze collections of data; implement simple search and aggregation algorithms
Week 6

Classes and Objects

Objects, classes, fields, constructors, instance methods, encapsulation, this, access modifiers.

Lab focus: Design a first multi-class application
Week 7

Object-Oriented Design

Abstraction, composition, class relationships, static vs. instance members, enums, packages.

Lab focus: Model a real-world problem as interacting classes
Week 8

Inheritance and Polymorphism

Inheritance, overriding, super, abstract classes, interfaces, dynamic dispatch.

Lab focus: Build a polymorphic class hierarchy
Week 9

Exceptions, File I/O, and Testing

Exceptions, try/catch, checked vs. unchecked exceptions, file I/O, defensive programming, unit testing.

Lab focus: Read and write structured files; test and debug systematically
Week 10

Recursion and Algorithmic Thinking

Recursive definitions, base and recursive cases, call-stack reasoning; recursion vs. iteration.

Lab focus: Factorial, Fibonacci, binary search, recursive array and string problems
Week 11

Algorithm Analysis, Searching, and Sorting

Runtime growth; Big-O intuition; linear and binary search; selection and insertion sort; divide and conquer.

Lab focus: Implement and experimentally compare algorithms
Week 12

Lists and Dynamic Data Structures

Array-based lists, linked lists, nodes, references, Java ArrayList, representation tradeoffs.

Lab focus: Implement a simple linked list; compare it with ArrayList
Week 13

Stacks, Queues, Sets, and Maps

Stack and queue ADTs; applications; hashing intuition; HashSet, HashMap.

Lab focus: Expression checking, queue simulations, frequency tables
Week 14

Trees and Core Data Structures

Trees, binary trees, BSTs, traversal, recursion on trees; priority queues and heaps.

Lab focus: Implement, search, and traverse a binary search tree
Week 15

Putting It Together: Software Design

Choosing data structures, interfaces vs. implementations, modularity, testing, debugging, reading APIs.

Lab focus: Capstone development and code review
Week 16

Integration and Transition to Graduate CS

Comprehensive review; complexity reasoning; abstraction; code comprehension; preparing for advanced courses.

Lab focus: Capstone demonstrations, cumulative assessment, graduate-readiness exercises

Using the decks

  • ← → or Space move between slides — Esc or O opens the slide overview.
  • S opens the speaker view, where the full prose from the lecture notes sits beside each slide.
  • F goes fullscreen; Ctrl+F searches the deck; ? lists every shortcut.
  • Click a ▸ grey bar to expand a short aside in place; click a ＋ blue pill to open a concept deep-dive. Esc closes it.
  • To export a deck as PDF, open it with ?print-pdf on the end of the address and print to PDF in landscape with background graphics on.
  • Everything runs offline — reveal.js and the syntax highlighter live in assets/, so the whole slides folder can be copied to a classroom machine or a USB stick.

All sixteen decks share one stylesheet, assets/csc500.css — edit it once to restyle the whole course.

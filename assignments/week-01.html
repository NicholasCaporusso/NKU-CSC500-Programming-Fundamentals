CSC 500 — Practice Assignments

Week 1: Computational Thinking and Java Basics

These assignments are designed to reinforce the topics introduced in Week 1 without reproducing the examples, labs, or homework problems in the lecture notes.

Unless an assignment explicitly asks only for analysis or pseudocode, write a complete Java program with an appropriately named public class and a main method.

For programming assignments:

  • use meaningful variable names;
  • use consistent indentation;
  • include comments only where they explain useful intent, assumptions, or reasoning;
  • predict the program's important results before running it;
  • compile and test the program;
  • compare the actual behavior with your prediction.

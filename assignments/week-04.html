CSC 500 — Practice Assignments

Week 4: Methods and Program Decomposition

Total assignments: 50
Difficulty scale: 1–5
Assignments per difficulty: 10

Unless an assignment says otherwise:

  • Write Java methods as public static methods.
  • Use only concepts introduced through Week 4.
  • Give methods descriptive lower-camel-case names.
  • Do not place a method definition inside another method.
  • Keep main focused on coordinating the program rather than performing all calculations itself.
  • Where a method is supposed to calculate a value, return the value rather than printing it.
  • Test your methods with several inputs.
